# Generated Results

These files are generated by `python -m src.experiments` with the configuration
in `run_metadata.json`.
`SHA256SUMS` records the generated artifact digests for transfer checks.
Verify it from this directory with `shasum -a 256 -c SHA256SUMS`.

The committed benchmark is synthetic. Its percentages are useful for testing the
method and code, not for estimating the impact of a real data center portfolio.
See `docs/RESULTS.md` for interpretation and `docs/THREATS_TO_VALIDITY.md` for
limitations.

Do not edit the CSV or JSON outputs by hand. Change the source or experiment
configuration, rerun the command, review the seed-level tables, and then update
the written interpretation.
